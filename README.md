# Fake Job Detection System

## Overview

The **Fake Job Detection System** is a Machine Learning-based web application developed during my internship as an **AI & Data Science Intern at Zeptoware Pvt. Ltd.**

The system helps identify fraudulent job postings by analyzing job descriptions and classifying them as **Real** or **Fake** using Natural Language Processing (NLP) and Machine Learning techniques.

The primary objective of this project is to protect job seekers from scam job advertisements and improve trust in online recruitment platforms.

---

##  Features

- Detects fraudulent job postings
- NLP-based text preprocessing
- Machine Learning classification models
- Deep Learning-based prediction
- Web-based user interface
- Real-time prediction
- User-friendly and interactive design

---

##  Dataset

- Dataset Size: **17,000+ job postings**
- Contains both genuine and fraudulent job advertisements
- Used for training and evaluating machine learning models
- Includes job descriptions and recruitment-related information

##  Workflow

1. Collect and prepare the dataset.
2. Perform data preprocessing.
3. Clean and transform textual data.
4. Apply NLP feature extraction techniques.
5. Train Machine Learning and Deep Learning models.
6. Evaluate model performance.
7. Deploy the best-performing model using Flask.
8. Predict whether a job posting is Real or Fake.
